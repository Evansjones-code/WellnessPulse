# WellnessPulse Welcome to **WellnessPulse**, a modern Android fitness and health-tracking application built with Jetpack Compose, Kotlin, and Health Connect. ## Developer * **Developer:** Evans Kotut Kiplagat * **Role:** Software Developer & Data Operations / Systems Support Engineer ## Features * **Live Workout Tracking:** Real-time workout tracking screen (`LiveTrackerScreen` and `ActiveTrackerScreen`) supporting various workout types. * **Health Connect Integration:** Secure synchronization and permission handling with system health metrics. * **Modern Android Architecture:** Built completely with Jetpack Compose for a responsive, material-designed UI. ## Getting Started 1. Clone the repository. 2. Open the project in Android Studio (Hedgehog or newer). 3. Sync Gradle and run the app on a physical device or emulator with USB Debugging enabled.
